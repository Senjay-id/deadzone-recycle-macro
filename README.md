Manual recycle macro for [Dead Zone Revive](https://store.steampowered.com/app/3919900/Dead_Zone_Revive/)

![img](https://i.imgur.com/lLkOA34.png)


# Building
Clone the project\
Build

# Installation
2 different version, framework dependent requires [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/id-id/download/dotnet/thank-you/runtime-desktop-8.0.30-windows-x64-installer) meanwhile self contained doesn't require it in exchange for bigger file size.

Extract anywhere and run the app

# Usage
* Run the executable
* Open the inventory in-game
* Input the coordinate accordingly
* Run the macro
