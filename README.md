Clone the project\

* 2 different version, framework dependent requires [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/id-id/download/dotnet/thank-you/runtime-desktop-8.0.30-windows-x64-installer) meanwhile self contained doesn't require it in exchange for bigger file size.

Download and extract anywhere

# Usage
* Run the executable
* Open the inventory in-game
* Input the coordinate accordingly, conveniently you can use the keybind below to automatically set their position depending on your mouse cursor
* Input the delay that you want, I recommend 1500ms with random delay enabled
* Input the loop count depending on your item count or just 1000 if your planning on recycling all the junk
* Run the macro
* Press P button to stop the macro prematurely

F1 = Set item position position\
F2 = Set recycle button position\
F3 = Set confirm button position

P = Emergency stop button to the macro
